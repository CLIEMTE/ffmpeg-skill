### Step 2: Find the Downloaded File

Once the download finishes, open your "Downloads" folder. You'll see a file named "ffmpeg-skill" (it may be a compressed ZIP file). Your browser might show it as a folder icon or a zipped folder icon - both are normal.

### Step 3: Extract the Files

If you downloaded a ZIP file:

1. Right-click on the ZIP file
2. Select "Extract All" or "Extract Here" from the menu
3. Choose a destination folder (your Desktop works well) and click "Extract"

After extraction, you'll have a folder called "ffmpeg-skill" containing all the necessary files.

### Step 4: Verify FFmpeg Is Installed

This skill requires FFmpeg to work. Don't worry - checking is easy:

1. Open the Start menu and search for "Command Prompt"
2. Type `ffmpeg -version` and press Enter
3. If you see version information, you're all set
4. If you see an error message, visit [ffmpeg.org](https://ffmpeg.org/download.html) and install the Windows build, then restart your Command Prompt

### Step 5: Set Up Your AI Assistant

The exact setup depends on which AI assistant you use (Claude Code, Cursor, Codex, or MCP). In general:

1. Open your AI assistant
2. Look for a "skills" or "tools" directory/folder
3. Copy the "ffmpeg-skill" folder into that directory
4. Restart your assistant

For detailed setup instructions for your specific tool, check the "Documentation" folder included in the download.
